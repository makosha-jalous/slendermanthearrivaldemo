# Slenderman — Minecraft Forge 1.19.2

Мод добавляет Слендермена: высокий (ровно 4 блока) моб в чёрном костюме с квадратной бледной головой и 6 толстыми щупальцами.

## Как он себя ведёт

- **Стоит неподвижно** почти всё время. Ходить и прокладывать путь он начинает **только когда игрок на него не смотрит**
  (он вне поля зрения). Как только игрок смотрит на него, он мгновенно замирает. Ходит короткими рывками
  (1,5–4 с) и стоит между ними (3–8 с).
- **Прыжок вплотную (jumpscare):** когда он почти лицом к лицу с игроком, он резко вытягивает руку прямо к голове игрока,
  наклоняет торс вперёд, а голова наклоняется вниз к игроку. Поза держится **ровно 2 секунды (40 тиков)**,
  после чего он **мгновенно** возвращается в прямую неподвижную стойку.
- Щупальца вырастают, если долго смотреть на него, и плавно, тяжело извиваются.
- Телепорты: far / mid / close / vanish (как раньше).

Команды (нужны права оператора):

```
/slenderteleport far|mid|close|vanish
/slenderteleport auto on|off
```

## Как получить готовый .jar (ничего устанавливать не нужно)

1. Создай на GitHub пустой репозиторий (например `slenderman`).
2. Загрузи туда **всё содержимое этой папки** (кнопка *Add file → Upload files*, перетащи файлы и папки;
   папка `.github` обязательна — в ней сборка).
3. Открой вкладку **Actions** → последний запуск **Build mod**. Через несколько минут он станет зелёным.
4. Внизу страницы запуска, в блоке **Artifacts**, скачай `slenderman-mod` — внутри будет `slenderman-1.0.0.jar`.
5. Положи jar в папку `mods` Minecraft 1.19.2 с Forge (43.x).

Если запуск красный, открой его и пришли мне текст ошибки.

## Настройки в коде

`SlendermanEntity.java`:

- `LUNGE_TICKS = 40` — сколько держится поза (40 тиков = 2 с);
- `REACH_TICKS = 3` — за сколько тиков рука вытягивается (резко);
- `LUNGE_RANGE = 3.4` — дистанция, на которой он вообще может прыгнуть на игрока;
- `WALK_BURST_*`, `REST_*` — длительность рывков ходьбы и пауз.

`SlendermanModel.java`:

- `LUNGE_LEAN` — насколько наклоняется торс, `LUNGE_HEAD_TILT` — доп. наклон головы;
- `TENT_WIDTH` — толщина сегментов щупалец.
